## Descripción

Este repositorio contiene la resolución de la tarea práctica de la Unidad III, enfocada en la implementación y utilización de los algoritmos DDA y Bresenham para el trazado de líneas sobre imágenes ráster utilizando Python y Pillow.

## Ejercicio 1 - Composición geométrica con DDA

Se utiliza el algoritmo DDA para generar una composición gráfica de una casa.

El programa genera el archivo:

`casa.png`

## Ejercicio 2 - Roseta con Bresenham

Se utiliza el algoritmo de Bresenham para generar patrones geométricos mediante puntos distribuidos sobre una circunferencia.

Cada punto se conecta con todos los demás puntos mediante líneas trazadas con Bresenham.

Se generan tres variantes:

- N = 12
- N = 24
- N = 36

Archivos generados:

`roseta_12.png`  
`roseta_24.png`  
`roseta_36.png`
